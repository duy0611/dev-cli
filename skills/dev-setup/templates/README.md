# Templates

- `devcontainer.json`: copy it to `<project>-dev/devcontainer.json` and create
  with `--config <project>-dev/devcontainer.json`, or to the project's own
  `.devcontainer/devcontainer.json`. The file must keep the name
  `devcontainer.json` (or `.devcontainer.json`).
- `agents.yaml`: copy it to `<project>-dev/agents.yaml` and pass
  `--agent-config <project>-dev/agents.yaml`, or to `.devcontainer/agents.yaml`.
