# Plugins baked into the dcx-base image at build time.
#
# Format, tab or space separated:
#   marketplace <name> <github-repo-or-git-url>
#   plugin      <name>@<marketplace>
#
# Lines starting with # are ignored. Marketplaces must appear before the
# plugins that come from them.
#
# This is baked, not installed at container create: changing it means
# rebuilding the image. That is the trade for instant, offline container
# starts, which matters here because instances are cheap and numerous.
#
# PUBLIC SOURCES ONLY. GHE marketplaces need an SSH agent or `gh auth login`,
# neither of which exists during a build, and a failure here fails the build.
# Install those by hand inside a running container.
#
# Every plugin costs context and image size. Keep the list to what a sandbox
# session actually uses.
